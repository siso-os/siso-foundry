## What Agent Base should take

1. **A derived "needs you" board, from Orchestrator.inc.** Its Kanban columns are computed from session, PR, CI and review facts rather than set by hand. The Agent Base dashboard should derive each agent's state the same way, from herdr pane status, the worktree's PR and CI, and a "waiting on Shaan" flag, so the registry cannot drift from reality.
2. **A coordinator that never does the work and a `## Remember` writeback, from Herdr Projects.** It runs on herdr already. Its coordinator only briefs and tracks. Every thread brief carries the project goal, standing instructions and memory, and lessons a thread files under `## Remember` flow back into `MEMORY.md`. Agent Base can copy that brief template and writeback convention directly, or adopt the plugin itself (MIT).
3. **Claim-once handoffs and an agent inbox, from ai-memory.** HANDOFF.md is a convention. ai-memory makes a handoff typed and owned, and lets exactly one successor claim it. It also has a directed inbox with a "you have mail" notice at session start. That would replace fire-and-forget `herdr-send` for messages that must not be lost. Its files-are-truth, rebuildable-index design fits `.agents/memory`.
4. **Close the PR feedback loop automatically, from Orchestrator.inc and Herdr Projects.** Both send failing CI checks and review comments back to the agent that owns the branch, and Herdr Projects removes the worktree (never forced) once the PR merges. Agent Base's per-task worktrees should get the same ticker.
5. **One daemon, many thin clients, plus an encrypted relay for the phone, from Paseo.** Paseo's daemon plugins render on desktop, web and mobile at once, and its relay or direct Tailscale connection reaches a home machine. That is the shape for reaching the Mac mini's agents from a phone without a hosted service.
6. **Diff annotation that goes back to the agent, from Orca.** Comments on individual diff lines are sent to the agent as follow-up instructions. That is a cheap review surface for the dashboard and beats retyping feedback into a pane.

## Where Agent Base is already ahead or different

Agent Base is a whole estate rather than a single app. It has a skills hub that projects one source into every harness, per-repo file memory alongside cross-project memory, cheap worker lanes (DeepSeek, Codex) chosen by task type, and two machines driven through herdr's agent API. The rivals each cover one or two of these. Orca, Paseo, Orchestrator.inc and Conductor are each a single GUI app that owns its sessions. Herdr Projects is the closest match because it runs inside herdr, but it is project-scoped and has no registry across projects. ai-memory covers memory only. None of them describes a shared skills library maintained across harnesses, or routing work by model cost.
